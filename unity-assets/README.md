# Don't Die logo assets

- `DontDieLogo.png` is the transparent wordmark for title screens and UI.
- `DontDieMark.png` is the compact skull-and-shield mark for icons.
- The matching SVG files are included as editable vector sources.

Import the PNGs into Unity as Sprites (`Texture Type: Sprite (2D and UI)`) with alpha transparency enabled. The SVG sources can also be imported with Unity's Vector Graphics package.
